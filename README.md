# Cable Courtship

> Your battery only charges when you date the right cable.

A mobile app that treats each charging cable as a romantic partner and assigns mood, jealousy, and compatibility rituals before letting your battery feel secure. The twist is that charging becomes a tiny dating game: cables get ghosted, smothered, or promoted based on how often you use them. It turns mundane battery maintenance into relationship management.

## Features
- Register charging cables with names, personalities, and relationship status.
- Track charging sessions and compute jealousy streaks when a favorite cable is ignored.
- Require tap rituals or compliments to unlock full-speed charging in the UI.
- Export a weekly diary of promoted, ghosted, and burned cable relationships.

## Stack
- Swift
- SwiftData
- Lottie
- CoreHaptics

## Getting started
```
Open the project in Xcode 15+, select an iOS 17 simulator, and run the CableCourtship scheme.
```
